# House map

One specific house, possibly several floors. Stairs have no special rules.

## Rooms
| Room | Role | Door | Mini-games |
| --- | --- | --- | --- |
| Living room | Meeting room, hub, where dead players wait | Open | None |
| Kitchen | Task room, open and visible | Open | Sort, Clean |
| Bathroom | Task room, small and isolated | Gated | Fuel |
| Bedroom 1 | Task room, isolated | Gated | Code entry, Card swipe |
| Bedroom 2 | Task room, isolated | Gated | Simon, Calibrate |
| Garage | Task room, far | Open | Wires, Steady hand |
| Garden | Task room, outdoor | Open | Download |

## Emergency event locations
| Version | Fix location |
| --- | --- |
| 1-player (4 players) | Garage or Garden, random |
| 2-player (5–6 players) | Garden + Bedroom 2 at the same time (farthest apart) |

## QR codes to print (9)
| Code | Count | Where |
| --- | --- | --- |
| Room task code | 6 | Inside each task room |
| Gated door code | 3 | Outside the Bathroom, Bedroom 1, Bedroom 2 doors |
Codes contain short IDs like `room-kitchen`, `door-bathroom`. Laminate the Garden code.
Body-report codes are shown on phones, not printed.

## Safety
- No running. Kills are a light tap on the shoulder or back, never a push.
- Kitchen: knives and hot surfaces put away. Garage: lights on, floor cleared, tools stored.
- Garden: daylight or lit area only.
